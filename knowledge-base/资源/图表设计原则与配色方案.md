## 问题
实施报告和教学设计中的图表应该怎么画、怎么配色才专业有效？

## 核心内容

**图表内容两项原则**

1. **只放你有别人没有的东西**
   - 岗课赛证是标配，不需要在赛和证里面过多描述
   - 图要表达的是文字的二次提炼
   - 策略图和资源图要有侧重：大家都有的放很小，大家没有的放很大

2. **不喜欢复杂的图，多等于没有**
   - 图是为呈现逻辑服务的，不是堆砌元素
   - 图的老师要把控的是"呈现逻辑"

**教学内容重构图的演进示例**
- 装配式施工作品：岗课赛证大家都有，跟企业合作大家都有
- 最终模糊掉证和赛——赛只写名字不写详细考点
- 重点放在教学内容上，用"单、多、全"这条线让外行知道从简单到复杂

**配色五统一原则**

| 统一项 | 说明 |
|--------|------|
| 实施报告图片配色 | 与课程属性、专业属性匹配 |
| 课件颜色 | 与学生衣服颜色、着装颜色一致 |
| 学生衣服/着装 | 工科类整齐划一，护理类可可爱爱，体育类体现体育精神 |
| 自己开发的网页颜色 | 与整体色调统一 |
| 现场赛老师穿的衣服 | 与所有视觉元素协调 |

**专业配色参考**
- 园林专业：配淡绿和深绿
- 整个团队的全部视觉要素——从图到视频到现场着装——统一考虑

**操作建议**
- 如果要节约时间，可以先画草图，不要纠结细节
- 最终定稿时由专人统一配色
