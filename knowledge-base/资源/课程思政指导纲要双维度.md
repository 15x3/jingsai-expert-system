## 问题
课程思政应该从哪些维度去挖掘？不同学科的侧重点是什么？

## 核心内容
必须学习教育部2020年三号文——《高等学校课程思政建设指导纲要》。文件从两个维度告诉专业课程如何挖掘课程思政元素：

**第一维度：公民基本素养**
- 作为公民应有宪法宗旨意识、法律意识
- 作为中国人应爱党爱国爱社会主义
- 主动传播社会主义核心价值观
- 传播优秀传统文化，热爱革命文化

**第二维度：学科特色挖掘**

| 学科类别 | 核心思政挖掘点 |
|---------|--------------|
| 农科 | 生态文明、三农情怀、乡村振兴 |
| 医科 | 医者仁心、救死扶伤、生命伦理 |
| 商科 | 经世济民、诚信经营、社会责任 |
| 工科 | 工程伦理、工程思维（非泛泛讲"工匠精神"——那是虚化泛化的） |
| 艺术 | 文化理解、文化自信、人文素养 |
| 人文 | 文化传承、人文关怀、价值引领 |

交叉学科应从多维度呈现。例如计算机类+文化艺术特征课程：人文维度关注文化理解和文化自信，工科维度关注创新精神和科技报国。不能人云亦云，也不能凭经验——要有科学方法的指导。
