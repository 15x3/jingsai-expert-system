## 问题
课程标准和实践条件中的实践课比例、双师比例应该如何填写才不被扣分？

## 核心内容
**实践课比例标准**：
- [ ] 中职和高职：实践课必须达到总学时的50%以上
- [ ] 职业本科：实践课不低于60%
- [ ] 出现理论课48学时+实践课16学时这种明显不符合50%的组合，一定会被扣分
- [ ] 课程标准第一页基本信息中，实践学时必须大于理论学时

**双师比例表述规范**：
- [ ] 文件一般要求不低于60%（但具体看各省文件）
- [ ] 比例必须与团队实际情况一致——如果团队4个人只有2人是双师（50%），文件中就不能写"一般不低于60%"
- [ ] 调整表述使其与团队数据自洽——如写成"一般不低于50%"
- [ ] 教学保障中的双师比例要跟团队成员对齐——有的团队保障中写"不低于90%"，实际团队中只有50%，这种自相矛盾必须调整
- [ ] 2026年文件精神：从"双师型"升级为"三师型"（懂产业、懂技术、懂教学）

**一致性检查**：
- [ ] 人才培养方案中的实践比例 = 课程标准中的实践比例
- [ ] 人才培养方案中的双师比例 = 教学保障中的双师比例 = 团队实际比例
- [ ] 数据不能自相矛盾
