## 问题
所有参赛材料完成后，如何系统性核对材料之间的一致性？

## 核心内容
从人才培养方案到最后交出的视频，每一份材料都要经过统筹把关核对。核对要点如下：

**横向一致性检查（跨文件）**：
- [ ] 人才培养方案中的课程信息 = 课程标准中的课程信息
- [ ] 课程标准中的教学进度表 = 教案中的授课时间安排
- [ ] 课程标准中的总学时 = 各模块学时之和
- [ ] 人才培养方案中的总学时 = 各课程学时之和 ≥ 3000
- [ ] 实践课比例在三个文件中一致且 ≥ 50%
- [ ] 双师比例在人才培养方案、教学保障描述、团队实际构成中一致
- [ ] 先导课程和后续课程的课程名称在三个文件中一致

**纵向一致性检查（单文件内）**：
- [ ] 课程标准中各模块学时之和 = 课程总学时
- [ ] 教案中各环节时长之和 = 授课学时标注
- [ ] 教学目标→教学内容→教学评价三者能对应

**关键数据检查**：
- [ ] 学分 与 学时 按16:1换算后吻合
- [ ] 课程开设学期无时间冲突
- [ ] 所有日期、学期编号、班级名称无错误

**最终审查**：
学校层面应有统筹把关环节。课程团队负责人要统筹好——大家有争议有讨论，但当争议阻碍前进时，负责人必须推动团队往前走。
