## 问题
教案的封面和目录应该遵循什么格式规范，避免因格式问题被扣分？

## 核心内容
教案封面与目录的格式规范：

**封面要求**：
- [ ] 简明朴实——所有文字材料要求白纸黑字
- [ ] 不在封面上加图案、花边、点缀元素（修饰越多，可能扣分越多）
- [ ] 必须包含：参赛组别、课程名称、专业代码、学时
- [ ] 字体推荐微软雅黑或黑体（庄重感）
- [ ] 内容部分用仿宋或宋体
- [ ] 字号和1.5倍行距按文件要求

**教案基本要素（目录/结构）**：
必须包含以下内容，放在表格里体现设计合理、重点突出、前后衔接、规范完整、详略得当：
- [ ] 授课信息
- [ ] 内容分析
- [ ] 学情分析
- [ ] 教学目标
- [ ] 教学策略
- [ ] 教学活动安排
- [ ] 课后反思

**常见扣分项**：
- 封面有装饰性图案或花边
- 授课信息缺项（六条任一缺失）
- 格式混乱——字体不统一、行距不统一
