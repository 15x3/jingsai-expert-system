## 问题
什么样的教案才叫"有实施性"？如何判定教案能否直接拿去上课？

## 核心内容
教案的实施性是指：让评审专家觉得这份教案是有内容的、有使用价值的，可以直接拿到课堂里去实施，而无需二次备课。

**实施性判定标准**：
- [ ] 不仅有教学流程（第一步、第二步、第三步），还有具体教学内容
- [ ] 如果只有流程没有具体内容，任何人拿到这个教案都没法上课——必须经过长时间的二次备课才能上，这就是不合格的
- [ ] 教师活动跟学生活动理清楚——谁做什么、什么时候做、怎么做
- [ ] 写明具体内容是什么——不是只写"讲解XX知识点"，要写清楚讲什么内容、举什么例子
- [ ] 思政映射用什么方式标注出来——是讲解、视频、讨论还是其他形式
- [ ] 教案有完整性和操作性——评委不用猜"这里老师要讲什么"

**反面信号（不具备实施性的标志）**：
- [ ] 教案只列出了教学流程框架（第一步干什么、第二步干什么、第三步干什么）
- [ ] 教学内容部分只有标题/提纲，没有具体的内容展开
- [ ] 教师活动和学生活动是空泛的描述性语言，不是具体的教学动作

**关系要求**：
教案必须体现师生活动，让另一个人拿过来对着教案就能基本完成这节课的教学。
