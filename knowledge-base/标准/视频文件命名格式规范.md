## 问题
参赛视频文件应该如何规范命名？

## 核心内容
虽然省厅文件对命名要求不是特别具体，但建议参照国赛标准执行：

**命名格式：**
```
教案序号 + 第几学时 + 教案页码 + 教学环节名称
```

**示例：**
"教案1_第2学时_P3-5_项目引入与任务布置.mp4"

**额外标注要求（专业课程二组）：**
如果视频包含实操和教学指导环节，还需标注实操起止时间：
```
教案序号_第几学时_教案页码_教学环节名称_实操（第X分X秒-第X分X秒）
```

**关键注意：**
- 教案页码以PDF编码为准，而不是自己给教案编的页码。
- 教案设计中必须注明教学环节名称——命名无法脱离教案的内容。
- 所有文件命名要统一、规范，不要出现拼写错误。

**文件交付建议：**
要求拍摄团队同时交付两个版本：
1. 提交版：符合比赛要求的MP4格式，500兆以内。
2. 高清版：用作实施报告中的截图佐证，清晰度更高。
