## 问题
教学目标中的行为动词应该用什么？哪些词不能用？

## 核心内容
教学目标的行为动词表达必须精准，这是可评可测的基础。

**知识目标推荐动词（由低到高）**：
- 了解 → 熟悉 → 理解 → 阐述 → 学会
- 体现递进关系：先写低层次，再写高层次

**能力目标推荐动词**：
- 能运用、能操作、能设计、能完成、能表达
- 特别要强调：语言表达能力、文字表达能力、沟通表达能力

**不推荐的动词**：
- [ ] "掌握"——表述不准确、过于笼统，无法评价。"掌握某某知识""掌握电工电子技术的基础知识"这种表述就是不合适的
- [ ] "学习"——不能作为教学目标动词，因为无法衡量是否"学习"了

**递进关系检查**：
- [ ] 目标之间是否由简到难：先简单后复杂，如先"了解"再"熟悉"再"理解"
- [ ] 不能出现"熟悉"在"了解"之前这种倒序
- [ ] 不能一个目标就笼统写完——要有层次感

**可评可测检验方法**：
写出目标后自问：这个目标能不能被评价？如果能用一个具体的测试题或操作任务来检验，就是可评可测的。
