## 问题
课程标准和课程开设方面有哪些常见的错误和必须遵守的规范？

## 核心内容
**课程标准常见扣分项**：

- [ ] 只改了16个学时的内容，其他学时内容一点没动——专家能看出参赛模块是"顶配"，其他是"毛坯"
- [ ] 新增授课计划表里的内容跟教案内容不对应——数据自相矛盾
- [ ] 学情分析不客观不精准
- [ ] 教学目标可评可测功能不强

**课程开设规范检查**：

- [ ] 专业课程分类：按"专业基础课→专业核心课→专业拓展课"的规范来写，不要用老的"专业（技能方向）课程"表述
- [ ] 2025年以后的学生，要写"某某领域课程"——体现课程是动态的、变化的
- [ ] 习近平思想概论必须开设
- [ ] 财经商贸大类专业必须增加习近平经济思想
- [ ] 形势教育四选一：党史、国史、改革开放史、社会主义发展史（任选一门即可，不需要每门都开）
- [ ] 2025级必须增加人工智能通识课程
- [ ] 专业必开的公共基础课程必须开设，不开就扣分
- [ ] 参赛课程在人才培养方案中要框选出来

**学时统计检查**：
- [ ] 中职总学时不低于3000——如果算出来2900多学时就是基本错误
