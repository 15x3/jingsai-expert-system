## 问题
教学进度表中的信息应该如何与课程标准、教案保持一致？

## 核心内容
教学进度表是课程标准的重要附件，数据一致性是基本规范问题。

**对应检查清单**：
- [ ] 课程开设的学期与课程标准中"以授课班级为例"的教学进度表对应——不能有时间冲突
- [ ] 新增授课计划表里的内容必须与教案内容对应一致
- [ ] 教学进度表中的课时分配与教案中的学时标注一致
- [ ] 教案的学习课时时间与课程标准授课计划表一致

**常见错误**：
- [ ] 课程标准中某课程在第3学期开设，教学进度表中写成了第2学期
- [ ] 教案标注2学时（90分钟），但进度表中该内容只分配了1学时
- [ ] 新增教学计划内容在进度表中找不到对应——评委对照时会认定为数据造假
- [ ] 只改了16个学时的参赛内容，其他学时内容没动——被评委看出参赛模块和其他模块系统性断裂

**校对方法**：
材料之间的系统性要由做事细致的负责人把关核实。建议做一份交叉对照表：
- 人才培养方案中的课程开设学期 → 课程标准中的教学进度表 → 教案中的授课时间，三个文件中的信息应当完全吻合。
