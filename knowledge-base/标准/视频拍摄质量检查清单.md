## 问题
视频拍摄完成后，如何系统检查视频质量是否符合比赛要求？

## 核心内容

**一、画面呈现检查**
- [ ] C位镜头是否能看到C位学生的正面和操作（而非全程后脑勺）
- [ ] 机位是否最大程度上呈现了学生实操的细节
- [ ] 评委想看到的场景是否被机位遮挡
- [ ] 学生实操过程是否清晰可见

**二、声音检查**
- [ ] 小组讨论的声音是否能被评委清晰听到
- [ ] 教师讲授声音是否清晰
- [ ] 是否在各组放置了收音设备

**三、内容匹配检查**
- [ ] 视频中是否呈现了实施报告中提出的所有关键点（育人模式→教学内容→学情策略→资源→实施效果→特色→改进）
- [ ] 视频用词是否与实施报告原文一致
- [ ] 是否是压缩课——教案写90分钟，45分钟就拍完
- [ ] 黄金三分钟内是否点出了今天要解决的核心问题和三个关键工序

**四、学生状态检查**
- [ ] 学生是否真实参与（非摆拍点头鼓掌）
- [ ] 是否有学生从零到一的明显进步
- [ ] 是否允许学生犯错和现场纠正
- [ ] 是否呈现了学生大量实操的活动

**五、视觉统一检查**
- [ ] 课件颜色是否与学生着装颜色协调
- [ ] 网页颜色是否与整体配色统一
- [ ] 工科类是否整齐划一 / 护理类是否温暖可亲 / 体育类是否体现体育精神

**六、户外拍摄专项检查**
- [ ] 户外场景是否做了只有在外场才能做的事
- [ ] 在教室能解决的问题是否放在了教室而非户外

**七、视频时长与设计一致性**
- [ ] 每个视频是否严格45分钟
- [ ] 是否避开了前45分钟"老师独角戏"的无效模式
- [ ] 标题语是否使用了实施报告中的原词
