## 问题
实施报告写完后缺少系统性的检查方法，不知道从哪些维度验证质量？

## 核心内容
可以制作自查清单——一致性的检查、关键信息的筛查，像观测点一样达到了打勾，达不到改进。

**整体结构检查：**

- [ ] 四大板块是否齐全？（教学整体设计、教学实施过程、学生学习效果、反思改进措施）
- [ ] 四大板块间逻辑线是否清晰？（设计→实施→效果→反思）
- [ ] 是否形成了闭环？（结尾呼应开头的问题）
- [ ] 结构层次是否分明？

**内容质量检查：**

- [ ] 理念是否贯穿全文？（OBE/PBL/建构主义等）
- [ ] 学情分析是否有数据和理论支撑？
- [ ] 教学目标是否可评可测？
- [ ] 内容重构逻辑是否清晰？
- [ ] 课程思政是否有层次结构？
- [ ] 教学策略是否经得起推敲？
- [ ] 实施过程是否按设计执行？
- [ ] 学习效果是否有量化和质性双证？
- [ ] 教学评价是否覆盖三维（过程/结果/增值）？
- [ ] 教学反思是否查摆了真问题？
- [ ] 特色创新是否独特且有推广价值？

**格式规范检查：**

- [ ] 字符数是否≤5000？
- [ ] 图表数量是否≤12张？
- [ ] 单张表是否≤半页？
- [ ] 有无无效装饰？
- [ ] 专业术语使用是否恰当？
- [ ] 行文是否精炼（短句、无长句）？
- [ ] 有无明显的AI化文本迹象（过多引号、破折号、假大空表述）？

**核心提醒：**
无论报告写得多好，始终源自教学做得好、上课上得好——只有这些才是支撑走得久远的底层力量。
