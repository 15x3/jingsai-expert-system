## 问题
在网评阶段，评委主要通过哪些维度判断作品是否值得进入现场赛？

## 核心内容

网评阶段能否取得好成绩，对照以下清单逐项检查：

**赛道维度**
- [ ] 赛道是否选好——专业大类是否匹配学校优势、区域特色
- [ ] 是否利用了跨校合作名额优势（如有）
- [ ] 是否对本赛道历年获奖趋势做过AI分析

**课程维度**
- [ ] 课程是否呈现了对行业前沿的匹配性
- [ ] 实施报告中的新技术、新规范、新标准、新方法是否在视频中有证据
- [ ] 选题方向是否符合国家刚需

**材料一致性维度**
- [ ] 四个视频是否与实施报告高度匹配（非"两张皮"）
- [ ] 人培→课标→教案→实施报告→视频是否逻辑一致
- [ ] 视频中关键用语是否与报告原文一致

**实施报告维度**
- [ ] 是否有独特的育人模式（高度足够高）
- [ ] 前言是否"抱学校大腿"——国字号省字号资源是否充分利用
- [ ] 是否写明了合作企业在行业中的地位
- [ ] 校企合作是否双向呈现（学校帮企业做了什么）
- [ ] 是否有能力图谱或个性化评价体系

**视频维度**
- [ ] 机位是否展示了学生实操细节（而非后脑勺）
- [ ] 是否呈现了学生大量参与的活动
- [ ] 配色是否协调统一
- [ ] 是否避开了无效教学设计模式（前15分钟老师讲→巡堂→鼓掌坐下）

**命中判断标准**
- 拿到三等奖但视频不错的作品，通常是实施报告出了问题
- 网评阶段的成绩主要取决于以上维度的综合表现
- 进入现场赛后，真正拉开分值的靠老师和团队
