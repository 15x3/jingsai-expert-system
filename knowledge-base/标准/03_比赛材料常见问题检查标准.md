## 问题
提交参赛材料前如何系统性地检查避免低级但致命的问题？

## 核心内容
以下是从评审视角总结的常见问题，可作为自查标准。

**检查项一：一致性（最高频问题）**

- [ ] 人才培养方案与教案：课时是否一致？课程名称是否一致？教学内容是否一致？
- [ ] 修改了一处材料，是否同步修改了其他相关材料？（改教案→同步改课程标准、实施方案、人才培养方案）
- [ ] 内容设计与课程标准是否一致？
- [ ] 视频内容与教案内容是否一致？
- [ ] 标准中的评价系统设计是否与实施报告一致？

**检查项二：视频真实性问题**

- [ ] 学生操作出现明显错误时，教师有没有为了完成剧本当没看见？
- [ ] 视频与教案是否对应同一教学环节？
- [ ] 视频是否回应了教学重难点？

**检查项三：整体观感问题**

- [ ] 是否出现要素堆砌？（像拼盘一样各说各的）
- [ ] 关联是否弱？（各部分之间没有逻辑联系）
- [ ] 层次是否混乱？
- [ ] 主线是否不清？

**检查项四：核心逻辑**

- [ ] 所有材料是否是一个整体？（是一套教学设计在不同材料中的形式化体现）
- [ ] 教学重难点是否与学情分析对应？
- [ ] 视频是否呼应教学模式和教学理念？
- [ ] 是否解决了最开始埋下的教学问题？

**补救原则：**
开始设计时就做一体化系统设计；尾声阶段交叉查验每份材料。
