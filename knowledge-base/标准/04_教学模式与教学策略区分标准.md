## 问题
自己凝练的"DE111P"之类的命名，到底是教学模式还是教学策略？

## 核心内容
以下三个条件逐一验证，判断是否符合教学模式的层级。

**是否为教学模式的三个判断条件：**

条件一：**有理论依据？**
- 是→可能是教学模式。如BOPPPS有建构主义理论支撑，OBE有成果导向理论支撑。
- 否→更可能是教学策略。自己命名的模式需说明基于什么理论。

条件二：**形成了固定的活动框架和程序？**
- 是→符合模式特征。有固定的步骤和环节序列。
- 否→偏向策略。只提供了方向性指导，没有固化流程。

条件三：**经过实践检验？**
- 是→可能是成熟的模式。如ADDIE在全球范围被反复验证。
- 否→偏向策略。还是团队自身的探索尝试。

**判定结果矩阵：**

| 有理论依据 | 有固定流程 | 经实践检验 | 判定 |
|-----------|-----------|-----------|------|
| 是 | 是 | 是 | 教学模式（如BOPPPS、ADDIE、OBE） |
| 是 | 是 | 否 | 新型教学模式（需说明尚在验证中） |
| 是 | 否 | 否 | 教学策略（有理论指导但未形成固定流程） |
| 否 | 任意 | 任意 | 教学策略（不是教学模式） |

**常见教学模式参考：**
BOPPPS、ADDIE、OBE、PBL、对分课堂——这些都有理论基础、固定流程和经过实践检验的体系。

**使用教学模式的注意事项：**
- 用了某模式，意味着接纳了它的教学理念、理论、范式和评价体系
- 如果后面操作跟模式不搭嘎→必须说明"进行了本地化优化和调整"
- 两个模式混合→需考虑适配性和兼容性
