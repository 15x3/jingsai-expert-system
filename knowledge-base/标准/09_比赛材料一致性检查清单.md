## 问题
多份参赛材料之间容易产生不一致，如何用清单系统性地排查？

## 核心内容
一致性是最基本的问题——到了材料打磨最终阶段，必须把关一致性。改了一个地方，要想到其他地方要不要对应。

**体例一致性检查：**

- [ ] 课时：人才培养方案 vs 教案 vs 实施报告 —— 课时是否一致？
- [ ] 课程名称：三份材料中的课程名称是否完全一致？
- [ ] 教学内容：三份材料描述的教学内容范围是否一致？
- [ ] 教材信息：教材名称、版本、出版社是否一致？
- [ ] 授课班级：班级信息在三份材料中是否一致？

**内容一致性检查：**

- [ ] 内容设计 vs 课程标准 —— 教学内容的范围和深度是否匹配？
- [ ] 视频内容 vs 教案内容 —— 视频场景是否对应教案中的教学环节？
- [ ] 标准中的评价系统 vs 实施报告中的评价系统 —— 评价维度是否匹配？
- [ ] 报告中的教学步骤 vs 教案中的教学步骤 —— 如报告写"五步教学"，教案不能写成"四步"
- [ ] 教学模式名称：三份材料中的命名和表述是否统一？

**修改联动检查：**

如果你在教案中修改了以下任何一项，请同步检查：
- [ ] 改教学内容 → 课程标准需同步？
- [ ] 改课时安排 → 人才培养方案需同步？
- [ ] 改教学目标 → 评价体系需同步？
- [ ] 改教学模式 → 实施报告需同步？
- [ ] 改教学策略 → 教学反思需同步？

**核心原则：**
所有材料其实都是一个整体——一套教学设计在不同材料中的形式化体现。所有逻辑都应该一样，是一个系统。
