## 问题
教案应该如何体现创新性和教师个性化特色？

## 核心内容
**创新性判定标准**：
- [ ] 不能跟其他教案都一个模型——看不出高低差异
- [ ] 教案不是教材或课件的简单搬家——不能只写提纲
- [ ] 一定有教学设计——具有可操作性，能落地实施
- [ ] 体现职业教育特点——能力提升的特点
- [ ] 信息化手段要能解决重难点问题

**个性化体现方向**：
- [ ] 口才好的老师：选择理论性强的部分来授课——发挥语言优势
- [ ] 操作动作好的老师：选择操作性强的内容来授课——发挥技能优势
- [ ] 树立特色意识——教案要形成并体现出教师的教学个性化

**推广性要求**：
- [ ] 大赛文件强调"推广性"——同样是教这门课的老师拿过来就能用
- [ ] 不能拿过来看不懂、教不下去
- [ ] 教案要既有个性又能通用——个性化的教学风格+标准化的教学流程

**创新加分建议**：
- 专业一组尽量采用专业二组的教学方式去参赛——虽然专业一组强调理论，但可以把实操部分纳入，动作比别人多就容易获奖
- 信息化程度解决方式更高大上一点也容易获奖
- 选择操作性比较强的课程内容来参赛更有优势
