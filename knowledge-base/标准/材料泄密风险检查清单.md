## 问题
提交材料前如何系统排查信息泄露风险，避免因小失大？

## 核心内容

**提交前必须留出2-3天专门用于核查信息**

**一、电子文档属性检查（最高频漏点）**
- [ ] 所有Word/PPT/PDF文档的作者信息是否已清除
- [ ] 文档属性中的公司/单位名称是否为空
- [ ] 文档创建者/最后修改者是否为匿名
- [ ] 注意：这是最容易遗忘的泄密点，晴天霹雳级别的失误

**二、课件内容检查**
- [ ] 课件截图中的小角落是否出现学校名称/Logo
- [ ] 课件底图/模板是否含学校标识
- [ ] 显示在屏幕上的教学平台是否暴露学校信息

**三、教案文件检查**
- [ ] 教案中是否出现学生照片（不允许——教案是前置的）
- [ ] 教案中是否出现教师真实姓名
- [ ] 教案中是否出现学校名称

**四、视频文件检查**
- [ ] 视频画面中是否出现学校名称/校徽
- [ ] 学生校服上的Logo是否可见
- [ ] 教室门牌/横幅等是否暴露学校信息
- [ ] 一体机/屏幕界面上是否显示学校信息

**五、实施报告检查**
- [ ] 报告中是否出现学校名称
- [ ] 报告中的照片是否暴露学校标识
- [ ] 报告的图片水印是否清除

**血的教训**
- 前年省里有个作品连续三年拿省一，奔着国一去，结果教案中截的课件某个小角落泄露了学校信息，直接没有成绩
