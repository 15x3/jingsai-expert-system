## 问题
怎样判定教学反思写得好还是不好？什么样的反思会被评委一眼看穿"没上过课"？

## 核心内容
**合格反思的判定标准**：
- [ ] 有细节描述——不能让评委一看就知道你没上过这门课
- [ ] 缺少实施痕迹的反思写得特别虚——评委大概也能写出和你一样的反思内容
- [ ] 反思字数：三四百字，不是一两句话
- [ ] 写设计和组织实施过程中遇到的问题、怎么纠偏、怎么优化
- [ ] 具体化描述：如设备操作环节花费时间比较长、一定程度拖慢了教学进度；VR设备数量不足、教学效果受到一定影响；周边设备投屏有延迟

**不合格反思的信号**：
- [ ] 笼统描述："本次课总体效果较好，学生参与积极"
- [ ] 没有具体问题——全是好话或空话
- [ ] 8份教案的反思高度雷同
- [ ] 问题和整改措施与教学内容没有针对性
- [ ] 写一两句话就结束了

**更高标准——在教案中体现反思迹**：
- [ ] 在手写批注中标注真实教学中的发现
- [ ] 如：导入新课、词汇运用、口语练习层层递进，但环节之间衔接有问题
- [ ] 如：学生对企业负责人发布的任务特别感兴趣，讨论热烈有强烈共鸣
- [ ] 反思写细节、写具体例子，让内容更加生动

**底线要求**：
团队一定要到课堂里实施验证——很多团队根本没到课堂里实施过，写出来的反思一眼就能看穿。
