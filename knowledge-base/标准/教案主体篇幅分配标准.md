## 问题
教案各部分的篇幅应该如何分配才算合理？

## 核心内容
教案篇幅分配应以课中实施为主体，其他部分精简：

**篇幅比例标准**：
- [ ] 课中实施部分：占整体教案的75%左右（十页教案中中间七八页为主体）
- [ ] 前面部分（授课信息、内容分析、学情分析、教学目标、教学策略等）：加起来约占15%（上下各三页以内）
- [ ] 课后反思：约占10%

**前面部分的精简原则**：
- [ ] 教学资源尽量用图标形式表述——如一个图标下面写"学习通"就够了，不需要更多描述
- [ ] 授课信息六条紧凑排列
- [ ] 学情分析用图表呈现——从教学平台抓取数据的可视化图表
- [ ] 教案前面这些内容不要占太多篇幅

**课中实施的主体地位**：
- [ ] 大赛文件明确：课中实施才是教案的主要篇幅
- [ ] 包含教学环节、教学内容、教师活动、学生活动、设计意图五要素
- [ ] 每个环节标注时长，所有环节时长之和与授课学时一致

评委看教案时，重点关注课中实施部分是否有内容——如果前面很长、中间很空，得分会很低。
