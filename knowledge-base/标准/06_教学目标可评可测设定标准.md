## 问题
教学目标写出来太模糊，评审无法判断是否真正达成？

## 核心内容
三维教学目标（知识、技能、素养）是基本功，三者缺一不可。核心要点：行为动词使用可观察可测量的词。

**行为动词选用标准：**

模糊动词（应避免）：了解、理解、掌握
→ 为什么模糊？学生说自己"掌握了"，怎么验证？

可评可测动词（推荐使用）：阐述、说出、明确、分析、辨认、辨别、独立完成、设计

**好的目标写法结构公式：**
在什么样的情境下 + 以什么行为 + 怎么完成一件事 + 达到什么样的标准

**知识目标示例与检查：**
- 合格："准确阐述工艺的基本原理和关键步骤"
  - [ ] 动词可观察？（阐述→可以听到）
  - [ ] 内容具体？（基本原理和关键步骤）
  
**技能目标示例与检查：**
- 合格："能独立完成设备的操作与调试，且调试准确率达到95%以上"
  - [ ] 有行为限定？（独立完成）
  - [ ] 有量化标准？（95%以上）
- 进阶："能在30分钟内独立完成设备调试工作"
  - [ ] 有时间限定？（30分钟内）
  - [ ] 有行为+标准？（独立完成+调试）

**素养目标示例：**
"在实操中培养细致严谨的工匠精神，并提升团队协作与沟通能力"

**分层设计要求：**
区分基础目标和拓展目标。高阶学生和低阶学生的目标可能都是"了解"，但深入程度不一样——能不能举一反三。教学目标越清晰，后面评价越好评。
