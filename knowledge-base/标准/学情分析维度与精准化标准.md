## 问题
学情分析应该从哪些维度来写？怎样才算精准？

## 核心内容
**公共基础课学情分析四维度**（缺一不可）：
- [ ] 知识基础——学生已有的相关知识储备
- [ ] 认知能力——学生理解和分析问题的能力水平
- [ ] 学习特点——学生的学习习惯、偏好、困难
- [ ] 专业特征——学生所学专业对其学习本课程的影响

**专业课学情分析三维度**（缺一不可）：
- [ ] 知识和技能基础——学生已有的专业知识和操作技能
- [ ] 认知和实践能力——学生的理解能力和动手能力
- [ ] 学习特点——学习风格、兴趣点和常见困难

**精准化判定标准**：
- [ ] 必须是针对接下来上的这两节课、这一次课来分析的——学生前期与这次课内容有关联的知识和认知是什么
- [ ] 不能空泛地写
- [ ] 6份或8份教案的学情分析不能雷同百分之六七十
- [ ] 既有整体分析，又有个体分析
- [ ] 数据来源清楚——学情分析图最好从教学平台（学习通、智慧树等）抓取日常积累的数据
- [ ] 分析结果为后面的教学重点难点和教学方法提供依据
