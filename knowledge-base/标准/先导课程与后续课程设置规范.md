## 问题
课程标准中先导课程和后续课程应该如何正确设置？

## 核心内容
**先导课程设置规范**：
- [ ] 先导课程必须是在本课程开设学期之前已修完的课程
- [ ] 不能把同期课程或后续课程写到先导课程里去——如电力电子技术应用在第三学期，那么综合设计课程（第四学期）的先导课程里应写上电力电子技术应用，而不是写同期课程
- [ ] 前导课程写"某某等"就够了，但内容一定要写对

**后续课程设置规范**：
- [ ] 后续课程是本课程之后学生将要学习的、与本课程有知识衔接的课程
- [ ] 课程开设的学期安排要跟教学进度表对应，不能有时间冲突

**跨材料一致性检查**：
- [ ] 课程标准中的先导/后续课程与人才培养方案中的课程开设学期一致
- [ ] 教学进度表中的授课班级、学期信息与课程标准一致
- [ ] 材料之间的系统性要由做事细致的负责人去把关核实

**常见错误**：
- [ ] 先导课程和后续课程写反了
- [ ] 把还没学的内容当作先导（学生不具备这个基础）
- [ ] 材料之间时间信息互相矛盾
