## 问题
教案的课中实施部分应该包含哪些要素？每个要素的要求是什么？

## 核心内容
课中实施是教案的主要篇幅（应占总篇幅的75%左右，即十页教案中中间七八页）。必须包含以下五个要素：

1. **教学环节**：
   - [ ] 分为课前预习、课程实施和课后拓展
   - [ ] 课前预习：网上或通过平台发布下节课的任务，反馈数据用于调整教学策略
   - [ ] 每个环节要注上时长

2. **教学内容**（主体的主体）：
   - [ ] 明确给学生讲什么
   - [ ] 标注哪些是重点难点
   - [ ] 包含知识点、任务、工作步骤、重要课件和信息化资源、思政元素

3. **教师活动**：
   - [ ] 根据教学内容条目中的知识点、任务、重点难点来安排教学方法
   - [ ] 说明为什么这么教、怎么教

4. **学生活动**：
   - [ ] 根据教师讲的内容进行自主学习
   - [ ] 与教师产生有效互动（不是一问一答）
   - [ ] 每个教师活动和学生活动要一一对应

5. **设计意图**：
   - [ ] 对应前面内容表达想达到什么目的
   - [ ] 强调做中学、学中做
