## 问题
教学能力比赛中教案的评分标准是什么？

## 核心内容
教案初评的评分标准分为三个大维度：

**第一维度：要素完整与规范**
- [ ] 教案要素完整规范
- [ ] 目标准确
- [ ] 教案之间衔接有序
- [ ] 若干份教案之间的关联、衔接、差异能分清楚，不雷同

**第二维度：教学目标与重难点**
- [ ] 教学目标具体清晰、表述准确
- [ ] 重点突出
- [ ] 可评可测——每个目标都能被评价
- [ ] 教学难点预判精准
- [ ] 教学内容支撑教学目标

**第三维度：教学内容质量**
- [ ] 教学内容科学严谨
- [ ] 容量适度——不过多也不过少
- [ ] 时代性强——教材不要过于老化，紧跟时代步伐
- [ ] 课内部分占75%左右的比例

**附加评审要点**：
- 授课信息写得全不全、有没有不当之处
- 教案的学习课时时间与课程标准授课计划表是否一致
- 每份教案是否聚焦具体的教学内容
- 教案是否体现了师生活动，信息化手段是否解决了重难点问题
